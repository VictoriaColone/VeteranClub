# 服务端安全实现与运行约定

## 注入与越权

- MyBatis SQL 使用 `#{...}` 参数绑定。SQL 语句、排序和表名都来自固定代码，不接受请求中传来的 SQL 片段；搜索的 `%`、`_` 与转义符按字面量处理。
- 请求体只允许白名单字段，校验字符串、整数、金额、数组长度、游戏、状态和布尔类型；不能提交 `role`、`earnings`、`commissionBps` 绕过服务端计算。
- 页面使用 Vue 文本转义，不把服务介绍或备注作为 HTML 执行。CSV 导出对公式起始字符与前导空白做保护。
- 所有订单读写检查所有者、受邀成员、参与者或员工角色。审核、派单、退款、管理员动作各自检查权限；隐藏按钮不作为权限依据。
- 真实服务器不存在演示登录、模拟支付成功、重置数据和模拟走满时长接口。

## 认证与会话

- 用户验证码六位随机数、五分钟有效、最多五次错误、单次使用。库中保存 HMAC，不保存明文验证码。
- 员工密码 BCrypt cost=12，长度至少 12 位并包含字母和数字，最多 72 UTF-8 字节。每个员工独立账号，全部角色均要求 TOTP。
- TOTP 使用 RFC 6238，六位码、30 秒窗口，允许相邻一步时钟偏移；已使用的时间步不可重放。挑战五分钟、最多五次错误，首次绑定密钥加密保存。
- 会话为随机 256 位不透明 token，数据库只保存哈希。H5 的用户／员工各自使用 HttpOnly、Secure、SameSite=Strict Cookie；修改请求必须提供和会话匹配的 CSRF token。登录等匿名接口另有 Origin 白名单和 JSON Content-Type 保护。
- 小程序使用独立的用户 Bearer，会话保存在小程序本地；员工不提供 Bearer 登录。H5 HTTP 模式不将认证 token 写入 LocalStorage。
- 用户会话七天；员工最长八小时、30 分钟无活动失效。退出或账号停用立即撤销；没有不可撤销的长效 JWT。
- 手机号 AES-256-GCM 加密，HMAC 索引，员工用户目录仅返回脱敏手机号；验证器密钥同样加密。加密与 HMAC 使用不同密钥。

密码存储选择遵循 [Spring Security 密码存储说明](https://docs.spring.io/spring-security/reference/features/authentication/password-storage.html)；CSRF 机制依据 [Spring Security CSRF 说明](https://docs.spring.io/spring-security/reference/servlet/exploits/csrf.html)，此项目在自定义数据库会话过滤器中实现 cookie / bearer 两类请求的区别。TOTP 测试包含 [RFC 6238](https://www.rfc-editor.org/rfc/rfc6238) 的校验向量。

## 防刷与 IP 封禁

| 项目 | 当前默认 |
|---|---|
| 单手机号发送间隔 | 60 秒 |
| 单手机号发送上限 | 每小时 5 次、每天 10 次 |
| 单 IP 短信发送 | 每小时 30 次 |
| 全站短信预算上限 | 每天 200 条，可通过环境调整 |
| 单 IP 验证码／TOTP 校验 | 每分钟 30 次 |
| 员工密码登录 | 单 IP 每分钟 20 次；单账号每五分钟 10 次 |
| 失败自动封禁 | 单 IP 15 分钟内超过 20 次失败，封禁 30 分钟 |
| API 请求 | 单 IP 每分钟 1200 次，单账号每分钟 300 次 |
| 请求体 | 最大 64 KiB，包括无 Content-Length 的流式请求 |

限流计数与封禁保存在 MySQL，事务内更新，不因进程重启清空。封禁和失败次数不会随失败的业务事务回滚。普通流量达到频率上限返回 429，不直接永久封 IP，降低共享网络误伤。

`X-Forwarded-For` 始终忽略。只有 TCP 对端匹配配置中明确的代理 IP，才使用代理覆盖的 `X-Real-IP`；IP 仅接受字面地址，不允许主机名解析。管理员可通过 `/v1/admin/security/ip-bans` 查询、临时封禁或解除封禁，不能封自己的当前管理连接；所有封禁操作留痕。公网层还需要云平台提供的网络防护；应用限流不承担大流量 DDoS 清洗。

## 交易一致性

- 新建订单使用请求幂等键与用户行锁；相同键不同内容拒绝。
- 同单接取锁订单行；成员占单由 `busy_slot.player_id` 主键保障。
- 报酬 `(order_id,player_id)`、支付请求 `(user_id,request_key)`、通知事件、后台任务类型／业务 ID 均有数据库唯一约束。
- 支付、退款、内部记账、实际转账分别保存状态。未配置渠道返回 503，未知结果先查单，不能假定成功。
- 所有金额为整数分，服务端计算价格和 20% 服务费，协作尾差逐人补一分。订单保留价格与费率快照。

## 部署与密钥

默认 API 绑定回环地址；容器部署通过私有网络访问，不公开 MySQL 和 Java 端口。生产强制 HTTPS 来源、Secure Cookie，禁止本地短信收件箱。应用和数据库设置内存、连接数、SQL 超时、HTTP 超时及日志轮转。

`.local/`、数据库文件、日志、真实 `.env`、私钥和证书都被 Git 忽略。`*.env.example` 只有占位符。不要将本机联调账号或短信收件箱复制到生产环境。生产密钥应从 RAM 角色或部署系统注入；不要在 URL、异常、审计中记录密码或验证码。更换加密／HMAC 密钥需要显式迁移，不能直接覆盖已有密钥。

这是一组已实现并测试的基础防护，不能替代线上渗透测试、依赖维护、备份恢复与运行监控；不承诺不存在所有攻击面。
